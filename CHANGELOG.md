## [1.0.0] - 2024-01-XX

### Added
- Initial release
- eWeLink Open API V2 integration
- Device dashboard with real-time status
- Support for multiple device types:
  - Lights (brightness, color temperature, RGB)
  - Switches (single and multi-gang)
  - Smart plugs (power monitoring)
  - Sensors (temperature, humidity, motion, contact, smoke)
  - Motors (curtains, blinds, garage doors)
  - Thermostats
  - Fans
- Room-based device organization
- Search and filter functionality
- Demo mode with mock data
- Responsive dark theme UI
- Gateway status monitoring
- Signal strength indicators
- Battery level monitoring
- Auto-refresh for live updates
- Device control (on/off, brightness, color, motor control)
- Multi-channel switch support
- Gateway system stats (CPU, RAM, temperature)
- Environment configuration support
- Comprehensive documentation

### Technical
- React 18 with TypeScript
- Vite build system
- Tailwind CSS v4
- Lucide icons
- Axios for API calls
- LocalStorage for configuration persistence
